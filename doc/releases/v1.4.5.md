# PiliAurora v1.4.5

本版修复 Windows 直播首次播放的画面问题，并补充对应的验证工具。

## 修复

- 修复 Windows 直播首次播放画面全黑的问题。创建和扩容 ANGLE Surface 时不再生成并绑定额外的 GL 纹理，mpv 渲染上下文的纹理状态保持不变，播放日志中的 `INVALID_FRAMEBUFFER_OPERATION` 随之消失。

## 其它

- 新增 Windows 直播首帧探针（[windows_live_startup.dart](https://github.com/wallpap/PiliAurora/blob/main/tool/probes/playback/windows_live_startup.dart)），检查首次播放与刷新后的纹理像素、实际解码器和音频时间推进。
- 整理文档与注释中的防御性表述，范围说明改为正面陈述。

完整变更：[v1.4.4...v1.4.5](https://github.com/wallpap/PiliAurora/compare/v1.4.4...v1.4.5)。

Android 提供 arm64-v8a、armeabi-v7a 和 x86_64 安装包；Windows 提供 x64 安装程序和便携包。
