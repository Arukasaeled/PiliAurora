# PiliAurora v1.5.0

本版统一视频和直播的播放架构，并集中修复 Android Surface、Windows 独立窗口、弹幕刷新和诊断日志中的时序问题。

## 播放器统一架构

- 视频和直播统一通过 `PlaybackOwner`、`PlaybackSession`、`NativePlaybackRuntime` 协调查询、加载、播放意图、配置和原生资源。
- 请求、页面归属、媒体加载和输出使用独立代次；过期响应、迟到原生回调和旧输出不能覆盖当前播放。
- 播放状态区分用户意图、原生实际状态和 inhibitor。切画质、音轨、倍速、音量和超分不会错误继承旧请求或改写用户暂停意图。
- 点播和直播支持统一来源故障切换、音频恢复、后台媒体租约和有界关闭；最后一个页面或租约释放后才销毁原生播放器。

## Android

- 直播视频 Surface 在解码前准备，并等待有效视频轨、几何和选轨确认；无法确认时及时进入受控回退或失败状态。
- 修复 Surface 预挂载、输出释放和 JNI 回执时序，减少快速切源、暂停加载和退出播放器时的旧 Surface 复用风险。
- 加载过渡等待实际视频首帧；加载失败、直播断流和无有效尺寸会及时结算。
- 弹幕刷新请求与纹理消费时钟分离，避免相位校准产生间歇性长帧间隔。

## Windows

- 独立播放窗口在稳定视频纹理出现后再显示并交接声音，启动尺寸按目标显示器预先限制。
- 修复加载期间重复窗口、首帧前结束加载、非全屏底栏宽度和浅色主题菜单可读性问题。
- 音量统一为 0–100% 整数，支持滚轮、快捷键、静音和外部状态同步。
- 播放信息、弹幕设置和更多设置使用紧凑分类面板；直播线路和聊天控件保持可用。

## 诊断与稳定性

- 记录播放器初始化分段耗时、Android Surface 预挂载证据、首帧状态和原生释放耗时。
- 统一播放器日志与诊断分类，保留页面路由和子窗口来源；预期 HTTP/UI 失败不再产生误导性错误提示。
- Windows 子窗口日志支持暂停、导出、清除和断连后备存储，缓冲按条目数与字节数限界。
- 补充播放会话、输出代次、Canvas 弹幕、音频焦点、桌面窗口和冷启动测试。

## 修复

- 修复本地媒体首次加载忽略自动播放设置的问题。
- 修复直播候选无视频轨时未继续尝试下一来源的问题。
- 修复加载提示与独立窗口显示切换、播放器底栏安全区、Android 音量入口和设置菜单布局问题。

完整变更：[v1.4.5...v1.5.0](https://github.com/wallpap/PiliAurora/compare/v1.4.5...v1.5.0)。

Android 提供 arm64-v8a、armeabi-v7a 和 x86_64 安装包；Windows 提供 x64 安装程序和便携包。
