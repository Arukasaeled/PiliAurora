# PiliAurora v1.6.0

## 修复

- 修复长视频恢复播放时异常重载、进度丢失的问题，加载失败后重试会保留当前内容和恢复位置。
- 修复加载或切换内容时旧视频仍在播放、关闭播放页面后声音继续播放的问题。
- 修复视频结束后，后续状态更新可能再次触发播放的问题。
- 修复消息已读后未读角标更新不及时的问题。
- 修复倍速切换、松开长按倍速和拖动进度后弹幕位置回退、运动不连贯的问题，改善密集弹幕的显示。
- 修复动图恢复显示时的帧请求冲突，以及图片、页面和播放资源释放不完整的问题。
- 修复 Android 视频输出切换失败时的资源清理问题，以及 Windows 视频输出重建、窗口缩放时的资源冲突。
- 修复退出 Windows 应用时独立播放窗口未一同关闭的问题。

## 新功能

- 新增“增强黑名单屏蔽”，默认开启。在推荐、热门、搜索、动态和直播等内容列表中过滤已拉黑作者，支持分页的列表会继续加载内容补位。
- 新增“检查合作视频作者”，默认开启。对于列表已标识的合作视频，任一合作作者被拉黑时屏蔽整条视频。可在“设置 → 账号与隐私”中关闭该项，减少额外查询。

## 其它

- 调整视频和直播弹幕的显示调度，复用文字布局与图片缓存，并限制后台处理和缓存占用。
- Windows 弹幕自动跟随屏幕刷新节奏，移除手动帧率选项；Android 保留跟随屏幕及 30、60、90、120 FPS 选项。
- 按显示尺寸请求动图缩略图，减少大尺寸源图的解码开销。
- 统一设置页下拉菜单样式，更新大会员标识。
- 更新中英文项目介绍、界面截图和使用文档，补充黑名单屏蔽说明。

Android 提供 arm64-v8a、armeabi-v7a 和 x86_64 安装包；Windows 提供 x64 安装程序和便携包。

完整变更：[v1.5.1...v1.6.0](https://github.com/wallpap/PiliAurora/compare/v1.5.1...v1.6.0)。
