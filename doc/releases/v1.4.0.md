# PiliAurora v1.4.0

本版新增原生表情包管理和新粉丝列表，调整消息与私信的状态处理。Windows 端修复了视频绿色条带、超分切换时的解码错误，以及播放器原生资源回收问题。

## 新功能

- 表情包管理改为原生页面，支持管理已拥有的表情包、查看可获取的表情包，并保留最近使用的表情记录。
- 消息页新增原生新粉丝列表，可在列表中关注或取消关注。
- Windows 收藏夹列表和表情包页签支持鼠标滚轮滚动。

## 消息与私信

- 主页角标、消息列表和私信共用当前主账号的状态，切换账号后使旧请求和订阅失效。
- 已读、删除、置顶和免打扰操作同步到共享会话状态，避免在途刷新覆盖操作结果。
- 私信和分享共用发送流程。发送失败或结果待确认时保留文本草稿；分享卡片已发出但附言失败时，分别说明两条消息的状态。
- 聊天在消息完成布局后确认已读，系统通知先展示内容再确认已读。

## 播放与显示

- 修复 Windows 部分 1080p 及以下视频出现绿色条带的问题。
- 修复 Windows 切换超分模式时，AV1 视频因解码器重建时序错误而丢失参考帧、触发硬解回退的问题。
- 补齐 Windows D3D11 硬件设备引用释放，调整 mpv 与 EGL 的销毁顺序；超分关闭和切换时重建渲染器，回收相关原生资源。
- 改进独立音轨读取中断后的恢复，保留可用缓存并按需重连音轨。
- 弹幕帧率设置修改后即时生效，轨道间距按实际渲染高度调整。
- 修复专栏部分段落和卡片缺失、最近表情尺寸异常，以及封面播放图标遮挡点击区域的问题。
- 直播醒目留言面板补回返回按钮和空状态提示。

## 构建与维护

- Windows 使用可从固定源码重建的 mpv 和 cnativeapi 预编译包，本地与 CI 校验构建材料及交付文件。
- Windows 构建复用 WebView NuGet 包和 Flutter 环境缓存。
- 更新消息模块、Windows 视频输出及构建排障文档，补充缓存、长 GOP AV1 和超分切换的回归检查。

## 下载与使用

- Android 提供 `arm64-v8a`、`armeabi-v7a` 和 `x86_64` APK，按设备架构选择。
- Windows x64 提供安装程序和便携 ZIP。使用便携版时保留解压后的完整目录。
- 私信提示“结果待确认”时，先核对聊天记录再决定是否重发。

## 验证范围

Windows 本机验证覆盖了缓存 AV1 播放、八次超分重建、有效纹理、暂停恢复和关闭超分后的内存回落。mpv 的 37 项测试、相关 Flutter 播放与视频输出测试，以及预编译包校验通过。

音频探针使用空输出；扬声器听感、其他显卡和驱动，以及直播中的超分切换在实机验证。
