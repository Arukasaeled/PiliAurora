# 弹幕合并与帧率设置

在播放设置的「弹幕与字幕」中调整，也可从视频播放器的弹幕设置面板进入。弹幕合并默认关闭；合并开关和字号放大参数修改后，重新打开播放页面生效；帧率修改立即生效。

## 弹幕帧率

默认「跟随屏幕」，也可选择 30、60、90、120 FPS。修改时保留当前弹幕与控制器，同步期间可能短暂波动。固定档位限制弹幕刷新频率，可降低绘制开销；实际刷新仍受屏幕刷新率和设备负载影响。该设置调整弹幕绘制节奏，视频帧率由媒体与播放器决定。

## 合并规则

相同或相似的弹幕在 20 秒内合并，显示首条原文及重复数量。窗口从首条弹幕开始计算，后续重复内容不会延长窗口。在线弹幕在每个加载分段内处理，本地弹幕文件整体处理；在线分段交界处保持独立。

匹配会统一全角英文、大小写、空白和常见标点，并归一连续重复的非数字字符。长度不足 8 个字符或超过 200 个字符的内容进行规范化后的相同匹配；8～200 个字符的内容允许少量编辑差异，数字和否定词差异保持独立。不同模式、自己发送的弹幕、字幕池与高级弹幕保持独立。屏蔽规则先于合并执行。

匹配状态最多保留 2048 个合并组，每条弹幕最多检查 64 个相似候选；高密度或大量不同内容下，部分重复弹幕可能保持独立。在线分段和本地文件的合并通过后台 isolate 执行，页面退出后的结果会被丢弃。

## 字号放大

「合并弹幕字号放大」默认开启，可独立关闭。放大阈值默认为 7，重复数量超过阈值时按对数增长；放大速度默认为对数底数 7，数值越小增长越快。字号保持至少原大小，最高两倍。放大的弹幕按实际高度占用多条轨道，普通弹幕沿用基础轨道间距。

## 轨道间距

「弹幕轨道间距」可在 1–3 倍之间调整，步进 0.1，默认 1.6。数值越小，同屏可容纳的轨道越多；轨道高度至少容纳普通文字与描边，轨道数量随字号、播放区域高度和显示区域比例变化。播放器面板中调整立即生效，全局设置用于后续打开的播放页面。Android 和 Windows 均按弹幕实际高度检查相邻轨道占用；设备显示效果仍需实机验证。

功能参考 [PiliNara 的增强合并弹幕说明](https://github.com/Starfallan/PiliNara#改动说明未来计划)。本项目使用有界编辑距离匹配，无新增拼音依赖。
